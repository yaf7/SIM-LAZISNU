# SIM-LAZISNU
Sistem Informasi Manajemen LAZISNU berbasis Laravel dengan integrasi Xendit Payment Gateway.

---
##  Fitur Utama

###  Autentikasi Satu Pintu
- **Unified Login**: Login yang sama untuk Admin dan User.
- **Auto-Redirect**: Admin masuk ke Dashboard Admin, User masuk ke Dashboard User secara otomatis.
- **Register**: Fitur pendaftaran akun baru bagi donatur masyarakat.

###  Dashboard User (Donatur)
- **Ringkasan Transaksi**: Info total donasi dan status pembayaran.
- **Laporan Grafik**: Visualisasi tren donasi bulanan.
- **Form Donasi**: Pilihan nominal cepat atau input manual.
- **Pengajuan Dana**: Mengajukan bantuan atau dana secara digital.

###  Dashboard Admin (Administrator)
- **Pengelolaan Donasi**: Verifikasi pembayaran (Approve/Reject).
- **Verifikasi Pengajuan**: Meninjau permohonan dana dari user.
- **Manajemen User**: Kontrol data seluruh pengguna terdaftar.
- **Statistik Kas**: Pantauan real-time Pemasukan, Pengeluaran, dan Saldo.
